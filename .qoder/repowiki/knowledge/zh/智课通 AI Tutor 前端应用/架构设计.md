- **分层架构**：采用经典的页面-服务（Pages-Services）分离模式。`src/pages` 负责 UI 渲染与交互逻辑，`src/services` 封装业务数据操作（如 `chatService`, `wrongQuestions`）及外部 API 调用（如 `deepseek.ts`）。
- **路由与状态管理**：使用 `App.tsx` 作为核心控制器，通过 `useState` 管理全局页面导航（`currentPage`）与用户会话状态，配合 `motion/react` 实现页面切换动画。
- **AI 集成层**：在 `src/services/deepseek.ts` 中集中处理与豆包（Doubao）大模型的交互，支持文本对话与多模态图片分析，并通过 `vite.config.ts` 配置开发环境代理以解决跨域问题。
- **多媒体组件化**：`VideoBackground.tsx` 提供自适应的视频背景能力，根据设备性能动态选择不同分辨率视频源，并在 `Login.tsx` 等页面中复用。
